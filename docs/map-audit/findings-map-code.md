## What is solid

- Layout is deterministic and cheap: 0.17 ms to build, about 3 ms to paint the biggest state, no overlaps in 987 checked states, and my extra real-label run of 412 selected-topic states also had none.
- Labels never lose content: wrapping replaced shortening, the accessible name is always the full label, and the 11 px rule held at every fit and target I measured (11.0 at 1440, 14+ at 375).
- Contrast is sound: check-contrast plus my hover/project/path sweep found no pair under 4.5:1 in either theme.
- No leaks: JS heap, DOM node count and listener counts stay flat over 100 map route changes and 50 mixed ones; only one set of window listeners exists.
- Rapid route changes, resize during animation, a bad saved state and reduced motion all behaved. The route is the source of truth for open branch and selection, the store only holds camera and offsets, and each project and path keeps its own state.
- Keyboard model is right: one roving tab stop, spatial arrows, Home to centre, Enter/Space keeps focus in the map through the route change.
- Data integrity around the map: every hard-coded `SYMPTOMS` id and all 19 `#/map/t/` ids in `91-map.js` exist; no duplicate node keys in any state; `SMELLS.length` and topic counts are computed, not typed.
