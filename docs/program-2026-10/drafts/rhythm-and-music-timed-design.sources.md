# Sources: rhythm-and-music-timed-design

Read = fetched and read the page (through a fetch summariser). Summary = only a search-result summary. Inference = my reasoning, no source says it.

- osu!standard windows 300: 80-6*OD, 100: 140-8*OD, 50: 200-10*OD; OD5 = ±50/±100/±150, OD10 = ±20/±60/±100. https://osu.ppy.sh/wiki/en/Beatmapping/Overall_difficulty (read)
- "about one frame at 60 Hz" for ±20 ms: arithmetic (16.7 ms frame). Inference.
- Beat, 16th and frame arithmetic (500 ms at 120 BPM, 83 ms 16th at 180 BPM, 16.7 ms at 60 Hz): arithmetic.
- Negative mean asynchrony: tapping to a steady metronome usually precedes the click by tens of ms; read as anticipation. Repp 2005, Psychonomic Bulletin & Review, https://www.doi.org/10.3758/BF03206433 (summary only; the publisher page blocked the fetch; the "tens of ms" magnitude comes from a search summary, check against the abstract). The "competing explanations exist" point is from the same summary (Paillard-Fraisse conduction-time hypothesis).
- Rhythm Doctor: one-button, press on the seventh beat of every bar, difficulty from polyrhythms, irregular bars, silent beats, visual distractions; one-button scheme inspired by Rhythm Heaven's two-button scheme and playable without sight. https://en.wikipedia.org/wiki/Rhythm_Doctor (read, secondary). Accessibility counts, screen reader, voice cues, single-button on gamepad/keyboard/mouse: https://www.familygamingdatabase.com/accessibility/Rhythm+Doctor (summary only, secondary). The developer's own notes page (https://7thbeat.notion.site/Rhythm-Doctor-v0-19-0-r40-24f90365a1618056a796e8e3185f5cca) would not load; Rhythm Doctor hit windows in ms NOT verified, and none are given in the topic.
- Crypt of the NecroDancer: Ryan Clark, turns shortened until they felt like a beat; skeleton moves every second beat; "Thriller" anecdote. https://en.wikipedia.org/wiki/Crypt_of_the_NecroDancer and https://gameranx.com/features/id/17305/article/crypt-of-the-necrodancer-interview-an-accidental-roguelike-rhythm-game/ (summary only, secondary). Not used as a quote.
- Hi-Fi Rush: world, enemies and obstacles sync to the beat; attacks still happen off the beat but are stronger in rhythm; UI beat indicators introduced gradually, a fully optional meter added; prototype had no graphics. https://vice.com/en/article/88qyw5/how-a-designer-known-for-horror-made-the-musical-gaming-triumph-hi-fi-rush (read, quotes John Johanas). The claim that animations interpolate to land on the beat even when input is early or late: https://en.wikipedia.org/wiki/Hi-Fi_Rush and a search summary of the Unreal Engine interview (https://www.unrealengine.com/en-US/developer-interviews/hi-fi-rush-was-inspired-by-shaun-of-the-dead-and-futurama; the fetch returned 403, so summary only; this is the weakest sourced claim in the topic).
- Metal: Hellsinger: Good/Perfect grade against the beat, Perfect gives more damage and Fury, beat system can be turned off, audio and visual calibration test added for wireless headphones and high-latency displays. https://www.trueachievements.com/n50185/metal-hellsinger-interview-the-outsiders and https://www.superjumpmagazine.com/metal-hellsinger (search summary only; trueachievements fetch returned 403).
- Rhythm Heaven: Tsunku teaches the team by singing and showing where the beat falls ("Here! Here! Here!"). https://iwataasks.nintendo.com/interviews/ds/rhythm-heaven/0/3 (read; a short excerpt, paraphrased, not used in the topic text). The Barista skip after three Try Again ranks and replay of introductions: https://rhythmheaven.fandom.com/wiki/Barista (search summary only, fan wiki; the topic says "the Rhythm Heaven games" and does not name a specific title; exact title coverage not verified).
- Unity AudioSettings.dspTime (double, sample-based, pauses with the game) and AudioSource.PlayScheduled (absolute time on dspTime timeline, schedule 100-200 ms ahead). https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AudioSettings-dspTime.html and https://docs.unity3d.com/6000.0/Documentation/ScriptReference/AudioSource.PlayScheduled.html (read). The pitfall that dspTime excludes Bluetooth/device delay is my inference from the definition.
- Godot sync recipe: get_playback_position + get_time_since_last_mix - get_output_latency; chunked mixing; discard decreasing readings. https://docs.godotengine.org/en/stable/tutorials/audio/sync_with_audio.html (read).
- Android: low_latency flag = continuous output latency of 45 ms or less; pro flag = round-trip 20 ms or less; no runtime API to determine latency. https://developer.android.com/ndk/guides/audio/audio-latency (read; the page is old and newer Android versions and Oboe may offer more, recheck).
- Rock Band separate audio and video calibration, negative values, per-TV starting values (LCD "Audio 80, Video 50"; units not stated in the page and not used in the topic). https://www.harmonixmusic.com/blog/how-to-calibrate (read). Automatic calibration via guitar camera/microphone: https://giantbomb.com/wiki/Concepts/Lag_Calibration (summary only, secondary; not used in the topic text).
- Beat Saber score 115 = 70 approach + 30 follow-through + 15 centre; no ms timing windows stated. https://bsmg.wiki/ranking-guide.html (read, community wiki). Map note time stored in beats (`_time` v2, `b` v3/v4): https://bsmg.wiki/mapping/map-format.html (read). Flow, parity, map prominent instruments not every sound ("mapper blindness", test with fresh players, downmapping): https://bsmg.wiki/mapping/intermediate-mapping.html (read).
- ITG/StepMania windows (ITG Marvelous 21.5 ms, Perfect 43, Great 102, Good 135, Boo 180; StepMania 22.5/45/90/135/180): forum summary at https://www.flashflashrevolution.com/vbz/home/forum/gaming/stepmania/63851-stepmania-timing-window-question (search summary only). NOT used in the topic text.
- Rhythm Heaven per-minigame windows (e.g. Karate Man ±35 ms): a search summary only, unsourced; NOT used.
- "Median of many taps" for calibration, "keep a loose pass window and tighten only the Perfect", "windows overlap when gap is under twice the window": design advice and arithmetic, no source. Inference.
- Not verified: how Crypt of the NecroDancer, Metal: Hellsinger and Hi-Fi Rush set their actual timing windows in ms; none is stated in the topic. Off-beat traps in Rhythm Heaven are described only in general terms; no named instance was verified. The facts' "asOf" date is the day of this write-up.

## Fact-check changes (2026-10-05)

Applied from rhythm-and-music-timed-design.factcheck.md. R = read by the fact-checker, S = secondary.

- osu! has no hit line: wording now says Guitar Hero, Rock Band, StepMania and Beat Saber use a hit line or travel toward the player, and osu! uses approach circles. Source: https://osu.ppy.sh/wiki/en/Beatmapping/Overall_difficulty and the osu! Approach rate page (R).
- Negative mean asynchrony: the "tens of ms" magnitude was not in the abstract, so it is removed (now "slightly before"). "Read as anticipation" is now stated as one of several explanations (sensory accumulation, P-centre, Paillard-Fraisse conduction time) and marked contested. Source: https://link.springer.com/article/10.3758/BF03206433 (abstract only).
- Entrainment: one sentence added, labelled a lens, not a design law. No separate source; it is a general term, not a numerical claim.
- Rhythm Doctor: "seventh beat of each seven-beat row" (Wikipedia: "every seventh beat"). "Screen reader and voice cues" replaced by narrated menus and play without vision, both listed on the Steam store data (publisher-declared): https://store.steampowered.com/api/appdetails?appids=774181 (R). Voice cues dropped as unconfirmed.
- NecroDancer: "began as a concept for a turn-based roguelike", not a built game. https://en.wikipedia.org/w/index.php?title=Crypt_of_the_NecroDancer&action=raw (R, S).
- Hi-Fi Rush: attribution fixed. The Vice article states "attacks still happen if the player is off the beat, but they're more powerful in rhythm" in the journalist's own voice, so "director says" and "Johanas said" are removed. https://www.vice.com/en/article/how-a-designer-known-for-horror-made-the-musical-gaming-triumph-hi-fi-rush/ (R). The beat UI wording now says only that the team's resistance to more UI broke down during development; "gradually" now describes the reader's own onboarding.
- Metal: Hellsinger "turn the beat system off": no readable source, so the claim is removed from the text (what, how, TECH, FACTS). Calibration: "has" replaces "added" (Prima, https://primagames.com/tips/how-to-fix-audio-video-lag-and-calibrate-it-in-metal-hellsinger, S); "audio and video" replaces "audio and visual".
- Android latency (OUTDATED): the NDK page is last updated 2024-01-03 and says no runtime API. Updated to say runtime estimates exist (Oboe AudioStream::calculateLatencyMillis; AudioTrack.getTimestamp) but miss Bluetooth, USB and HDMI/TV delay, so calibrate anyway. https://developer.android.com/ndk/guides/audio/audio-latency and https://github.com/google/oboe/blob/main/include/oboe/AudioStream.h (checker read; the writer did not re-read them).
- Rhythm Heaven Barista: now "some titles", fan-wiki description, with the OK rank and "three tries" details dropped. Titles not verified.
- Frame polling: reworded from "widens the window" to "shifts presses late by up to a frame, unevenly" (the checker's reasoning; no external source).
- Notelock added as an alternative to nearest-note matching, from the osu! Overall difficulty page already cited (R). The draft ±120 Pass table is noted as overlapping at 180 BPM sixteenths (arithmetic: 83 ms < 240 ms).
- Unity: dspTime advances per mixer buffer, so ErrorSec is quantised (about 21 ms at 1024 samples and 48 kHz). Inference from the documented definition; the Unity page does not say it. Input event timestamps: the Input System API (InputAction.CallbackContext.time) was not checked, so the text says to check it and does not name it.
- Godot snippet: get_output_latency now cached in _ready, because the AudioServer class reference says it can be expensive to call every frame. https://docs.godotengine.org/en/stable/classes/class_audioserver.html (R by the checker). Snippet is 14 lines.
- Style: "robust" replaced by "reliable".

Still not sourced: GDC talk on rhythm games, Tsunku/Iwata Asks use in text, 7th Beat developer posts, a named Rhythm Heaven off-beat trap.
